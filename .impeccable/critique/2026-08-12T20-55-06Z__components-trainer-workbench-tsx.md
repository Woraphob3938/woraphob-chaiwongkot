#### Priority Issues

**[P1] ช่องในตารางกดได้โดยไม่บอกกริยา**
- Why: ว่าง = ลบ, นัดเสร็จได้ = เสร็จ, นัดอื่น = แชต รูปร่างเดียวกัน
- Fix: ใส่คำบนชิป (ลบ / ฝึกเสร็จ / แชต) ห้ามใช้ “จัดการช่วงว่าง” แทนลบ
- Suggested command: /impeccable clarify

**[P1] ตารางยังไม่ใช่ที่ทำงานที่มีป้าย**
- Why: คำสั่งชัดอยู่ในลิ้นชักที่ปิด
- Fix: ให้แถวสัปดาห์กับรายการใช้คำเดียวกัน
- Suggested command: /impeccable layout

**[P2] การ์ดขั้นตอนบอกว่าพร้อมแล้วทั้งที่ยังมีนัดยืนยัน**
- Why: ระหว่างเซสชันต้องการชื่อคนถัดไป ไม่ใช่สถานะ idle
- Fix: ถัดไป = นัดถัดไป (ชื่อ + เวลา + แชต)
- Suggested command: /impeccable clarify

**[P2] เติมตารางยังทีละชั่วโมง**
- Why: งานหลักของเทรนเนอร์อิสระคือเปิดหลายช่อง
- Fix: เลือกหลายชิปแล้วเพิ่มครั้งเดียว หรือคัดลอกวัน
- Suggested command: /impeccable distill

**[P3] นัดบนบอร์ดโชว์รหัสจอง**
- Fix: เวลา + ชื่อ; รหัสเป็น metadata รอง
- Suggested command: /impeccable quieter
