## Design specificity

สีเขียวเข้มและเขียวมะนาว ตัวอักษรไทย และการเน้นคุณสมบัติทำให้หน้าเป็น FitConnect ชัดเจน ระดับความเฉพาะประมาณ 7/10 แต่รูปแบบยังเป็น marketplace card grid ทั่วไป และยังเปรียบเทียบความพร้อมจองกับคุณสมบัติได้ไม่ดีพอ

## Priority issues

1. **P1 — ตอน sidebar ขยาย การ์ดถูกบีบเกินไป:** คำว่า “ค่าฝึกต่อครั้ง” แตกเป็นแนวตั้ง ควรลดเหลือ 3 คอลัมน์เมื่อ sidebar ขยาย หรือใช้ grid ที่ปรับตามพื้นที่คงเหลือ
2. **P1 — ข้อมูลทดสอบลดความน่าเชื่อถือ:** ชื่อซ้ำ อักษรย่อเดี่ยว ประสบการณ์ 0 ปี ไม่มีรีวิว และไม่มีเวลาว่าง ทำให้หน้าดูไม่พร้อม หากเป็นข้อมูลทดสอบควรไม่เผยในผลสาธารณะจนโปรไฟล์พร้อม
3. **P2 — การ์ดที่จองไม่ได้เด่นเท่าการ์ดที่จองได้:** เก็บปุ่ม lime ไว้สำหรับ “ดูโปรไฟล์และเลือกเวลา” ส่วนรายการที่ยังไม่เปิดรับจองใช้ปุ่มรอง
4. **P2 — ภาพสำรองสีเขียวเข้มใหญ่เกินไป:** ใช้พื้นอ่อนกับอักษรย่อขนาดเล็กหรือไอคอนบุคคลแบบเรียบ โดยไม่สร้างรูปปลอม
5. **P2 — สถานะกับราคาใช้ความหมายปนกัน:** แยกราคา “ยังไม่กำหนด” ออกจากสถานะ “ยังไม่มีเวลาว่าง” และไม่แสดงข้อความซ้ำ

## Persona red flags

- **ผู้ใช้ใหม่:** ไม่รู้ว่า “ตรวจคุณสมบัติแล้ว” ตรวจอะไร และอาจคิดว่าตลาดไม่มีเทรนเนอร์พร้อมรับงาน
- **ผู้ใช้คีย์บอร์ด/โปรแกรมอ่านหน้าจอ:** ต้องผ่านลิงก์ไปโปรไฟล์ซ้ำหลายตำแหน่งในการ์ดเดียวกัน
- **ผู้ใช้มือถือที่รีบใช้งาน:** การ์ดสูงจากภาพและ metadata หลายบรรทัด ทำให้เปรียบเทียบหลายคนต้องเลื่อนนาน

## Minor observations

- เปลี่ยน “เลือกได้มากกว่าหนึ่งข้อ” เป็น “ใช้ตัวกรองร่วมกันได้”
- หัวข้อหลักของหน้ามีเฉพาะแบบซ่อนสำหรับ screen reader; ป้ายช่องค้นหาทำหน้าที่เป็นหัวข้อในสายตา
- ทดสอบหน้าจริงแล้วการค้นหา การล้างตัวกรอง จำนวนผลลัพธ์ และ URL ทำงานถูกต้อง
- ไม่พบ console error/warning และไม่มี page-level horizontal overflow

## Questions to consider

1. ต้องการให้ผลเริ่มต้นแสดงเฉพาะผู้ที่มีเวลาว่าง หรือแสดงทั้งหมดแต่แยกผู้ที่ยังไม่เปิดรับจอง?
2. เมื่อ sidebar ขยาย ต้องการ 3 คอลัมน์สบายตา หรือ grid อัตโนมัติตามพื้นที่?
3. โปรไฟล์ชื่อซ้ำเป็นข้อมูลทดสอบชั่วคราว หรือเป็นบัญชีจริงที่ข้อมูลยังไม่ครบ?
