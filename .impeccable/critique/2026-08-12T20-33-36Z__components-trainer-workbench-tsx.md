#### Overall Impression

ภาษาภาพของโต๊ะหลักฐานเทรนเนอร์ดีแล้ว แต่โหมด Operate ยังแยก “ดูตาราง” กับ “ลงมือทำ” คนละที่ โอกาสใหญ่ที่สุดคือทำให้ตารางเป็นที่ทำงาน ไม่ใช่โปสเตอร์ แล้วให้การ์ดขั้นตอนถัดไปตามนัดจริง

#### Priority Issues

**[P1] การ์ดขั้นตอนถัดไปไม่มองการจอง**
- **Why it matters:** เทรนเนอร์ที่มีนัดให้กดฝึกเสร็จยังเห็น “ตารางงานพร้อมแล้ว”
- **Fix:** เรียงความสำคัญเป็น นัดที่ฝึกเสร็จได้ → สัปดาห์ว่าง → เพิ่มช่อง แล้วชี้ไปที่การ์ดนัด ไม่ใช่ `#schedule`
- **Suggested command:** /impeccable clarify

**[P1] ตารางรายสัปดาห์ดูได้อย่างเดียว งานจริงอยู่ในลิ้นชักที่ปิด**
- **Why it matters:** เห็นชื่อและเวลาแล้วต้องเลื่อนไปเปิด `<details>` เพื่อลบช่องหรือบันทึกฝึกเสร็จ
- **Fix:** ให้ event กดได้ (ว่าง = ลบ/แก้, ยืนยันแล้ว = ฝึกเสร็จ/แชต) หรือยุบเป็นวาระถัดไปรายการเดียวที่ลงมือได้
- **Suggested command:** /impeccable layout

**[P1] บันทึกฝึกเสร็จเสี่ยงกว่าการลบช่องว่าง**
- **Why it matters:** ลบชั่วโมงว่างมีไดอะล็อกเตือน แต่ปิดเคสลูกค้าจริงกดแล้ว PATCH ทันที
- **Fix:** ยืนยันแบบเดียวกับการลบ: ชื่อสมาชิก + ช่วงเวลา + “บันทึกว่าฝึกเสร็จแล้ว”
- **Suggested command:** /impeccable harden

**[P1] ฟอร์มเพิ่มช่องชนกับกติกา 1 ชั่วโมง**
- **Why it matters:** เลือกนาทีอิสระได้ และปฏิทินสร้างช่องเริ่มอาทิตย์ แต่บอร์ดเริ่มจันทร์
- **Fix:** ชิปชั่วโมง, ให้ต้นสัปดาห์ตรงกัน, โชว์ช่องที่มีอยู่ของวันนั้นก่อนส่ง
- **Suggested command:** /impeccable distill

**[P2] ภาพรวม + คอลัมน์ว่างทั้ง 7 วัน**
- **Why it matters:** ตัวเลขสามช่องซ้ำกับตาราง และวันที่ไม่มีรายการสูง 14rem
- **Fix:** เหลือแถว “ถัดไป” หนึ่งแถว หรือวาระหนาแน่นบนจอแคบตั้งแต่ก่อน 58rem
- **Suggested command:** /impeccable quieter

#### Persona Red Flags

**Alex:** เพิ่มทีละช่อง ไม่มีคัดลอกสัปดาห์ ไม่มีทางลัดคีย์บอร์ด จะหนีไปใช้สเปรดชีต

**Jordan:** ปุ่มเพิ่มช่องถูกปิดโดยไม่มีเหตุผลข้างปุ่ม; “ล็อกชั่วคราว” ไม่ได้อธิบาย; สถานะโปรไฟล์ว่างไม่มีปุ่มในแผงนั้น ต้องพึ่งการ์ดขั้นตอนถัดไป

**Sam:** ปุ่มวันในปฏิทินราว 42 ปุ่ม; แถววัน `aria-hidden`; อีเวนต์ในตารางไม่ใช่ปุ่ม; ป้ายฝึกเสร็จอ่านรหัสจอง

**Casey:** CTA เพิ่มช่องไม่อยู่โซนนิ้วโป้งจนกว่าจะเปิด disclosure; ฝึกเสร็จอยู่ท้ายหน้าใน details ที่ปิด; ไม่มีทางเข้าแชตจากการ์ดนัด

**เทรนเนอร์อิสระระหว่างเซสชัน:** ต้องการว่าใครนัดถัดไป กดเสร็จ และทักลูกค้า ได้ตัวเลข ตารางนิ่ง และรหัสจองแทน
