## เป้าหมายของโปรเจกต์

FitConnect คือระบบจองเทรนเนอร์ส่วนตัว มีผู้ใช้ 3 บทบาท:

- **สมาชิก:** ค้นหาเทรนเนอร์ ดูใบรับรอง จองเวลา ชำระเงินผ่าน Stripe Checkout แชต และรีวิว
- **เทรนเนอร์:** สมัครพร้อมใบรับรอง เปิดช่วงเวลาว่าง ตอบรับคำขอ เชื่อมบัญชีรับเงิน Stripe และบันทึกผลการฝึก
- **ผู้ดูแลระบบ:** ตรวจใบสมัครเทรนเนอร์ จัดการบัญชี ดูการจอง การชำระเงิน และรายงาน

ลำดับขั้นของการจอง:

1. `pending_trainer`: รอเทรนเนอร์ตอบรับ
2. `awaiting_payment`: สมาชิกมีเวลาชำระเงินผ่าน Stripe 10 นาที
3. `confirmed`: ชำระสำเร็จ ระบบยืนยันให้อัตโนมัติ (ไม่มีใครตรวจสลิป)
4. `completed`

เป้าหมายตอนนี้คือขัด UX/UI ทีละหน้าให้ใช้งานง่ายและให้ข้อมูลถูกต้อง โดยทุกข้อความเป็นภาษาไทย และรองรับทั้งจอคอม (1440px) และมือถือ (375px)

## สภาพแวดล้อม

- **Front end:** Next.js 16 (อ่าน `node_modules/next/dist/docs` ก่อนเขียนโค้ด), TypeScript, Tailwind, `app/globals.css` และ `tokens.css`
- **Back end:** PHP REST API ใน `backend/` ทำงานผ่าน XAMPP ที่ `http://localhost/fitconnect-api` ฐานข้อมูลเป็น MariaDB ชื่อ `fitconnect`
- **บัญชีสาธิต** (รหัสผ่าน `password`): `member.demo`, `trainer.a`, `trainer.b`, `trainer.c`, `admin.demo` ทั้งหมดลงท้าย `@fitconnect.local`
- **rtk:** อย่ารัน `rtk vitest` หรือ `rtk tsc` ตรง ๆ ให้ใช้ `npm test` และ `npm run typecheck`
- **ชุดตรวจก่อนบอกว่างานเสร็จ:**
  - `npm run typecheck`
  - `npm run lint`: มีคำเตือนเดิม 2 จุด คือ `<img>` ในแชต และ `output/logo/refined.mjs`
  - `npm test`: ผ่าน 438 ข้อ
  - `npm run test:php`
  - `npm run test:payment-routing`
  - `npm run test:e2e`: Playwright 24 ข้อ อ่านอย่างเดียว

- **งานก่อนหน้า:** ตัวกรองเทรนเนอร์ใช้หัวข้อตามที่กำหนด, หน้ากรอกข้อมูลวิชาชีพเป็นวิซาร์ด 4 ขั้น, แท็บของแอดมินอยู่แถวเดียว, ตั้งชื่อสถานะ ("รอการชำระเงิน", "ชำระแล้ว", "ถูกระงับ"), หน้าจองมีปุ่มย้อนกลับ, รูปโปรไฟล์กดขยายได้, และปรับหน้ารีวิว
