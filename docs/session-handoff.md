## เป้าหมายของโปรเจกต์

FitConnect คือระบบจองเทรนเนอร์ส่วนตัว มีผู้ใช้ 3 บทบาท:

- **สมาชิก:** ค้นหาเทรนเนอร์ ดูใบรับรอง จองเวลา โอนเงินแล้วส่งสลิป แชต และรีวิว
- **เทรนเนอร์:** สมัครพร้อมใบรับรอง เปิดช่วงเวลาว่าง ตอบรับคำขอ ตรวจสลิปของตัวเอง และบันทึกผลการฝึก
- **ผู้ดูแลระบบ:** ตรวจใบสมัครเทรนเนอร์ และดูสลิปของยิมแบบอ่านอย่างเดียว (คนตัดสินสลิปคือเทรนเนอร์ที่ถูกจอง)

ลำดับขั้นของการจอง:

1. `pending_trainer`: เทรนเนอร์ตอบรับและเลือกรอบแจ้งสมาชิก 12:00 หรือ 18:00 น.
2. `awaiting_payment`: สมาชิกมีเวลาชำระเงิน 10 นาที
3. `payment_review`: เทรนเนอร์ตรวจสลิป
4. `confirmed`: แสดงเป็น "ชำระแล้ว"
5. `completed`

เป้าหมายตอนนี้คือขัด UX/UI ทีละหน้าให้ใช้งานง่ายและให้ข้อมูลถูกต้อง โดยทุกข้อความเป็นภาษาไทย และรองรับทั้งจอคอม (1440px) และมือถือ (375px)

## สภาพแวดล้อม

- **Front end:** Next.js 16 (อ่าน `node_modules/next/dist/docs` ก่อนเขียนโค้ด), TypeScript, Tailwind, `app/globals.css` และ `tokens.css`
- **Back end:** PHP REST API ใน `backend/` ทำงานผ่าน XAMPP ที่ `http://localhost/fitconnect-api` ฐานข้อมูลเป็น MariaDB ชื่อ `fitconnect`
- **บัญชีสาธิต** (รหัสผ่าน `password`): `member.demo`, `trainer.a`, `trainer.b`, `trainer.c`, `admin.demo` ทั้งหมดลงท้าย `@fitconnect.local`
- **rtk:** อย่ารัน `rtk vitest` หรือ `rtk tsc` ตรง ๆ ให้ใช้ `npm test` และ `npm run typecheck`
- **ชุดตรวจก่อนบอกว่างานเสร็จ:**
  - `npm run typecheck`
  - `npm run lint`: มีคำเตือนเดิม 2 จุด คือ `<img>` ในแชต และ `output/logo/refined.mjs`
  - `npm test`: ผ่าน 471 ข้อ
  - `npm run test:php`
  - `npm run test:payment-routing`
  - `npm run test:e2e`: Playwright 20 ข้อ อ่านอย่างเดียว
